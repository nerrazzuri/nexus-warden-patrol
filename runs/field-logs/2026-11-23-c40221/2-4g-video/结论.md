# 12-03 用户方案实测：机器人走 4G + Tailscale 连站点、站点看画面（2026-11-23 12:05–12:18）

连法：Orin 默认路线 → RK3588(192.168.168.168) → wlan0 连 ZTE U30 Air（5G 149 信道，跟热点同信道，热点不掉）→ Maxis 4G → Tailscale **直连**（没走 DERP）→ 笔记本（只连公司 WiFi，扮舞台电脑）。
为了不改证书：笔记本 tailscale 宣告 192.168.234.232/32（用户在管理页批准），这个地址临时挂在 lo 上；Orin 打开 accept-routes。

- 代理 MQTT 经 Tailscale 连上站点（切的时候离线 8 s，自己回来）。
- **画面一开始一直断**：SRT 握手失败（Input/output error）。原因：笔记本回包源地址选成 tailscale0 的 100.69.130.19，不是 192.168.234.232，SRT 认不出。普通 UDP 两边都通；SRT 直接推到 100.69.130.19 马上通。
  临时修：`ip route replace 100.67.176.60 dev tailscale0 table 52 src 192.168.234.232` → 画面马上来。**正式方案里机器人直接连笔记本的 Tailscale 地址就不会有这个问题**（证书要补 SAN，SRT 推流地址也用 Tailscale 地址）。
- 原画经 4G 上行：**3.4–3.6 Mbit/s，稳**（17 次 5 s 采样平均 2.85，含起流）。Tailscale ping 平均 90 ms，最高 526 ms。
- **用户看：画面有，延迟约半秒。**
- tailscale0 MTU 1280；DF ping 1252 过、1300 报 mtu=1280。
