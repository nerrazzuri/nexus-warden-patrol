# 12-03 演讲会：机器人一路走、大屏一路看画面

2026-11-22 定（用户：「12 月 3 号的 POC 其实是个演讲会……从另一个比较远的地方把机器狗挪到舞台上，大屏上要显示……最主要就是把摄像头显示出来」「机器狗很有可能从室外走进来」「要显示」→ 方案「同意」）。

- 机器人：C40221 + 竞品上装。
- 起点到舞台：远，室外进室内，中间墙多、转弯多。自己布 Wi-Fi 盖不住，也没有 Mesh。
- 舞台上除了画面要不要演示别的（看见人报警、喊话），看需求再定。

## 一、怎么连

```
 机器人热点 XG2WIFI_C40221 ──(笔记本自带 Wi-Fi)── 随行笔记本 = 站点（field-laptop）
                                                    │
                                     USB 手机共享网络（4G，两家运营商的卡备着）
                                                    │
                                         互联网 + Tailscale（只在我们自己的设备之间）
                                                    │
                                    舞台电脑：浏览器开站点网页 ── HDMI ── 大屏
```

- **机器人和站点一直在身边**：跟着机器人走的人背着随行笔记本，连机器人热点。这就是平时每次现场的连法，不改机器人、不改 R300S。
- **只有大屏这一段走 4G**：4G 卡了、断了，只是大屏那一下卡；机器人、站点、录像照常，网回来大屏自己接上。
- **机器人全程用厂家遥控器开**：遥控器直接连机器人，不经过我们的网。有人跟着、低速档。
- **为什么不让机器人整条路走 4G**：路上遥控、画面都要靠 4G，C02、C05（4G 下看画面、遥控）一次都没测过，会场人多时 4G 也挤。

这是一次临时走公网的连接（平时「先不搞公网」，11-21）。只在当天用，用完按第六节关掉。

## 三、提前在办公室做好（一次）

需要 PR #374（省流量，`video.lite` 可配）装进随行笔记本的站点；没装的话第 3 步跳过、用原画。

1. **Tailscale 账号**：用公司账号建一个 tailnet，只加随行笔记本、舞台电脑（要的话再加一部手机）。
   管理页里打开 MagicDNS 和 HTTPS Certificates（`tailscale serve` 要用）。
2. **随行笔记本装 Tailscale、把站点网页挂出去**（只在 tailnet 里能开，**不要用 `tailscale funnel`**，那是对整个互联网开放）：

   ```bash
   curl -fsSL https://tailscale.com/install.sh | sh
   sudo tailscale up                       # 浏览器里登录公司账号
   sudo tailscale serve --bg https+insecure://localhost:8443
   tailscale serve status                  # 记下 https://<笔记本名>.<tailnet>.ts.net
   ```

   - `https+insecure`：Tailscale 到站点这一段不核站点自己的证书（站点证书是我们自己的 CA 签的）。舞台电脑看到的是 Tailscale 发的正规证书，不报警告。
   - 站点证书不用重签，手机不用重新添加站点，机器人不用动。
   - 网页画面走 WebSocket，站点要求 Origin 跟 Host 一样；资料说 `tailscale serve` 会把浏览器那边的 Host 原样带过去，彩排时确认（C18）。不行就用第五节的退路。
3. **大屏用的小画面**：随行笔记本 `/etc/nexwar_site/site.json` 的 `video` 里加 `"lite": {"width": 960, "fps": 8, "q": 8}`，重启站点（`sudo systemctl restart nexwar_site`）。
   - 一路大约 3 Mbit/s（原画 5 帧约 4 Mbit/s；缺省小画面 640 宽、2 帧约 0.3 Mbit/s）。彩排时按 C21 选定当天用哪一档。
   - 舞台电脑的网页：右上用户菜单 →「省流量」开。
4. **机器人热点不当默认路由**（不然笔记本以为上网走机器人热点，4G 用不上）：

   ```bash
   nmcli -t -f NAME,DEVICE con show --active          # 找到机器人热点那条连接的名字
   sudo nmcli con modify "<机器人热点连接名>" ipv4.never-default yes ipv6.never-default yes
   sudo nmcli con up "<机器人热点连接名>"
   ```

   插上手机、打开「USB 网络共享」以后核对：

   ```bash
   ip route        # default 走手机那块网卡（usb0 / enx…）；192.168.234.0/24 走 Wi-Fi
   ping -c3 192.168.234.1 && ping -c3 1.1.1.1
   ```

5. **舞台电脑**：装 Tailscale、登录同一个账号；浏览器打开第 2 步记下的地址，登录站点，进值班页，前摄像头全屏。

## 四、当天

1. **提前一天进场**：起点、路线、舞台、控制台走一遍；舞台电脑接大屏试一次；两张卡在起点、路上、舞台各测一下网速（手机测速 App，记上行）。
2. **出发前 30 分钟**：
   - 随行笔记本插好充电宝，连机器人热点，插手机开 USB 共享，`ip route` 核一遍。
   - 合盖不睡眠（只管今天，不改系统设置；记下 pid，结束时按 pid 停）：

     ```bash
     systemd-inhibit --what=sleep:idle:handle-lid-switch --who=nexwar --why="12-03 演讲会" sleep 6h &
     echo $! > ~/inhibit-1203.pid
     ```

     要密码的话前面加 `sudo`。彩排时合上盖等 5 分钟核一次（C19）。

   - 网页上 C40221 在线、前摄像头有画面；舞台电脑大屏也有画面。
   - `tailscale status`：看舞台电脑那一行是 `direct`（直连）还是 `relay "sin"`（绕新加坡中转）。中转也能看，只是慢一点。
3. **走的时候**：随行的人离机器人 10–20 m 以内；厂家遥控器开，低速档。
4. **上台以后**：机器人停稳、站好；要演示别的（报警、喊话）照 `docs/POC当天操作单.md`。

## 五、出事了怎么办

| 现象 | 先做什么 |
|---|---|
| 大屏卡住、画面不动 | 看随行笔记本网页：有画面 → 是 4G 那段，等它自己接上或换卡；没画面 → 是机器人热点那段，随行的人走近一点 |
| 舞台电脑打不开站点地址 | `tailscale status` 两边都在线吗；随行笔记本 `tailscale serve status` 还在吗 |
| 网页能开、画面一直黑（WebSocket 被拒） | 退路：舞台电脑直接开 `https://<随行笔记本的 Tailscale IP，100.x.y.z>:8443`，浏览器说证书不受信任，点「继续」 |
| 4G 很慢 | 换另一家的卡；站点的小画面降一档（640 宽、5 帧），重启站点 |
| 随行笔记本没电 / 睡着了 | 站点停了，大屏和手机都没画面；机器人照样用厂家遥控器开。插电、开盖，站点自己起来 |
| 机器人有异常 | 厂家遥控器停；我们的网络跟它没关系 |

## 六、活动后改回

```bash
kill "$(cat ~/inhibit-1203.pid)"                      # 合盖照旧睡眠
sudo tailscale serve reset                            # 不再挂出站点网页
sudo tailscale down                                   # 断开 tailnet（要的话 tailscale logout）
sudo nmcli con modify "<机器人热点连接名>" ipv4.never-default no ipv6.never-default no
```

- `site.json` 里的 `video.lite` 可以留着（只影响开了「省流量」的观众）。
- 舞台电脑：退出 Tailscale；用的是会场电脑的话卸载、清掉浏览器里站点的登录。
- Tailscale 管理页里把舞台电脑删掉。
