# 1.1-4 远程喊话：按住说话 + 听回话（设计）

11-28 定。用户：「继续把所有1.1功能都做了」。

## 已经有的

- 打字喊话（`tts:<语言>:<文字>`）、常用喊话一句一个按钮、录好的话术。英文在 Orin 上用 Piper 合成，竞品只会念中文。
- 喇叭优先级仲裁：人手动的是 `MANUAL`，事件派遣、驱离的更高。

缺的是**保安自己的声音**。打字慢，现场要「你是谁？站住，保安马上到」这种话，按住说就行。还有**听现场**：机器人那头有人回话、有动静，保安听不到。

## 定下来的

| 项 | 定的 |
|---|---|
| 做法 | **按住说话、松开发送**（对讲机那种），不做实时双向通话。实时要 WebRTC、回声消除，现场 4G 也不稳；一段一段发，断网了也只是这一段没发出去 |
| 一段多长 | 最多 30 秒，到点自动松开；不到 0.6 秒的（点一下就松开）不发 |
| 格式 | App 录 AAC（m4a，16 kHz 单声道）；网页用浏览器自带的（多半是 webm / Opus）。站点原样存，**机器人那头用 ffmpeg 转成 48 kHz 双声道 wav**（跟英文合成同一个格式，竞品的 dmix、我们自己的声卡都放得了） |
| 怎么到机器人 | 站点存下，发喇叭命令 `clip = talk:<16 位编号>`；机器人从**狗专用口**（mTLS，跟拉地图同一套证书）`GET /talk/<编号>` 拉下来。只拉得到发给自己的那段 |
| 优先级 | 跟打字喊话一样，是人手动的（`MANUAL`）。驱离、事件派遣在放的时候回「忙」 |
| 听回话 | 机器人有麦克风才有这个按钮（能力里报 `mic`）。点了请机器人录 10 秒（3–20 秒），录完 `POST /talk/<编号>` 传回站点，保安在「最近的对讲」里点开听 |
| 麦克风在哪 | 竞品上装：配 `arecord_device`，SSH 到竞品主控跑 `arecord`（跟放音同一条路）；我们自己的上装：配 `audio.record_device`，本机 `arecord`。**没配就不报 `mic`** |
| 留多久 | 声音是个人数据：站点只留 **24 小时**，到点连文件带记录删。机器人上只留最近 20 段转好的 |
| 谁能用 | 说、听回话：保安、管理员（`dispatch`）。听录音、看记录：`view`。说了、听了都进审计（记编号和字节数，不记声音） |
| 老机器人 | 能力里没有 `talk` 的，站点回 409「要升级机器人软件」，不发命令。App、网页不显示按钮 |
| 浏览器 | 网页录音要 HTTPS（或本机）；不是的话按钮灰着，写原因 |

## 没做、以后做

- 实时双向对讲（WebRTC）。
- 录回来的声音自动降噪、自动转文字。
- 回话进报警的「经过」（现在只在机器人页的「最近的对讲」里）。

## 真机 / 现场要验的

- 竞品主控上有没有麦克风、`arecord -l` 是哪个设备；没有的话听回话这一块不出来（按住说话照样能用）。
- Orin 上有没有 ffmpeg（英文合成已经在用，应该有）。
- 现场 4G 下一段 30 秒的 m4a 多久能放出来（估计 1–3 秒）。
- 喇叭音量：人声比合成的轻，可能要调 `volume_percent`。

## 代码

- 协议：`nexwar_contract/deter.py`：`clip` 多认 `talk:<编号>`；新输出 `mic`（带 `clip` 和最多 20 秒的 `max_s`）。
- 站点：`talk.py`（`TalkDesk`：存、给机器人、收回话、到点删）；接口 `POST /api/robots/<id>/talk`（请求体就是录音）、
  `POST /api/robots/<id>/listen`、`GET /api/robots/<id>/talks`、`GET /api/talk/<编号>`；狗专用口 `GET|POST /talk/<编号>`；
  表 `talk_clips`；派遣器按能力 `talk` 挡老机器人。
- 机器人：`nexwar_agent/talk.py`（`TalkLink`：拉、转码、传回话）；`deter.py` 放 `talk:`、录 `mic`；能力里报 `talk`。
- 上装适配器：`anbot.py`（`talk_path`、`record`、`arecord_device`）、`payload.py`（`record_device`）、`hal.py`。
- 网页：`talkpanel.tsx`（机器人控制页「喊话」那一块）。App：`site_talk.dart`（上装页「喊话」那一块），录音库 `record 7.1.1`，
  Android 加 `RECORD_AUDIO`，iOS 加 `NSMicrophoneUsageDescription`。
- 测试：`site-node/tests/test_site_talk.py`、`test_site_intake.py`（狗专用口 + 真 ffmpeg）、`robot-agent/tests/test_deter.py`、
  `adapter-d1max/tests/test_payload.py`、`test_anbot_payload.py`、`contract/tests/test_deter_contract.py`、
  `web/console/src/talkpanel.test.tsx`、`mobile/test/site_talk_test.dart`。


## 外审 1.1 第 1 轮改的

- 录音下载、转码慢（先回执收下、后台接着放）：下完时如果期间有人关了喇叭、放了别的，这段不放了（喇叭指令有代次）。
- 听回话没成：机器人报的失败站点记成「没录到」（写原因）；等了 90 秒还没传回来也算没录到。网页、App 不再一直灰着「听回话」。
- 按住说话：要麦克风权限、开设备的时候松了手，不录、不发（以前会接着录到 30 秒自动发出去）。
- 录音到点删：文件删不掉的记录留着，下一次再删（以前记录删了、文件永远没人管）。

## 外审 1.1 第 2 轮改的

- 旧录音下载失败的时候，如果后来又有喇叭指令（可能优先级更高、正在放），不动它的状态，也不报失败。
- 听回话：网页、App 一直问到站点给结论（站点 90 秒没等到就标没录到），App 不再 32 秒就不问了；超过 90 秒的「等回话」不再挡着按钮，显示「没录到回话」。
