# 1.1-3 现有报警器一响 → 派机器人去核实（设计）

11-28 定。用户：「继续把所有1.1功能都做了」。

## 已经有的（W16、W73 第五期）

- 外部事件派遣：签名回调 `POST /api/incidents` → 按防区或设备位置找查看点 → 选机器人、以事件优先级派 `goto`。
- 外部设备按位置登记（门磁、报警主机、摄像头）：站点自己算查看点、所在防区，每台一个签名回调 `dev-<id>`。
- 布防判断、名单授权、同防区 60 s 合并、每个事件源每分钟限流、机器人看见人报 P1（`dog_sees_person`，W33 / W77 全自动处置）。

缺的两块：**报警器误报多**，原来一报就是 P1；**客户的报警器多半不会签名**，接不进来。

## 定下来的

### 一、先核实再报警

| 项 | 定的 |
|---|---|
| 开关 | 每台设备一个「先核实」。**新登记的门磁、报警主机默认开**；摄像头（AI 判过的）、其他默认关；老设备不变（关） |
| 报什么 | 开了的设备报警 → P2「报警器报警，机器人去核实」（`intrusion_verifying`，0x080C），给保安看，不推 P1 |
| 看见人 | 派去的机器人从报警起看见了人 → 那一路照旧报 P1「机器人看见人」（带警灯、喊话、跟人）；P2 关掉，写「核实：机器人看见人了」 |
| 没看见人 | 机器人到了（任务完成）、又过 30 s 没看见人 → P2 关掉，结论标「误报」，写「核实：机器人到了现场，没看见人（照片在这一趟记录里）」 |
| 没到现场 | 任务失败、中止、被抢，或 10 分钟还没到 → 另报 P1「有入侵，无机器人去：没核实成」，叫人 |
| 派不了 | 没机器人、没查看点、走不到 → 跟原来一样直接 P1「无机器人去」（没法核实就不能压成 P2） |

### 二、不会签名的设备怎么接

| 接法 | 给谁用 | 做法 |
|---|---|---|
| 签名回调（原来的） | 集成商、我们自己的程序 | 不变 |
| **触发网址** | 能「调一个网址」的设备：录像机、报警主机的 HTTP 联动、各种脚本 | 站点给一个带 32 位随机口令的网址 `/api/alarm-in/<口令>`，GET / POST 都行；口令只显示一次，站点只存哈希；可以换网址（旧的立刻作废） |
| **报警主机（SIA DC-09）** | 常见 IP 报警主机：Hikvision AX PRO、Ajax、Paradox、DSC、Risco 等都能报到「报警中心」 | 站点当接收机（TCP，端口在 `site.json` 的 `alarm_receiver.sia_port`，默认不开）。认 `SIA-DCS`、`ADM-CID` 两种格式，CRC 校验，回 ACK / NAK。**只收不加密的**，加密的回 NAK 并记日志（局域网里在主机上关掉加密）。按「主机用户号 + 防区号」对到设备（防区号空着 = 这台主机全部防区）。只有入侵类派机器人：SIA 的 BA、BV、PA、HA、TA；Contact ID 的 120–139、144、145 新事件。布撤防、恢复、故障、心跳只回 ACK |
| **干接点（IO 模块）** | 红外、门磁、围栏的干接点 | 接到一个以太网 IO 模块（Modbus TCP，几十到一两百块），站点每 0.5 s 读离散输入。常开 / 常闭可选；连着两次读到报警态才算（去抖）；一直报警只算一次，回到正常再报警才再算。IO 模块连着 1 分钟读不到报 P2「报警输入断了」（`alarm_input_lost`，0x080D），读到了自动解决 |

同一路（同一个主机防区、同一个 IO 输入）只能接一台设备，不然一次报警派两回。三种新接法进来以后跟签名回调走同一条路（限流、布防、授权、合并、选机器人）。

## 没做、以后做

- 加密的 DC-09（AES）；Contact ID 走电话线的老主机（要加一个 IP 转换器）。
- 火警（SIA FA、Contact ID 110–118）不派机器人：消防要按消防规范走，不能靠机器人。1.1-6 热成像再看要不要「冒烟、高温点」去看一眼。
- 机器人到了以后转一圈看（现在是到了朝向设备、拍一张，看见人由机器人自己报）。
- 「核实」这一段的画面自动推给值班员（现在值班员点开告警看机器人画面）。

## 真机 / 现场要验的

- 一台真的 IO 模块（比如 USR-IO808、Waveshare Modbus POE ETH Relay）接一个红外，走一遍「触发 → P2 → 机器人到 → 30 s → 关」。
- 一台真的报警主机配到站点的端口，看它发的报文是不是我们认的格式（各家的 SIA 细节有出入）。
