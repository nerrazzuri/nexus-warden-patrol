# 真机测试单 2026-11-10：新 D1 Max 裸机，静态测试，测完清干净

来源：用户 2026-11-10。一台新的 D1 Max，裸机、没有竞品上装。只做**机器人不用走**的测试；测完要把我们的包和文件
**全部清掉**，机器回到装之前的样子。

**三条规矩**

- **机器人全程不走。** 不发巡逻、不发 goto、不遥控开动、不建图。站点上这台机器人设成「只许手动派」（第 3 步），
  不建排程。站起、趴下也算动作，用户 11-10 已同意，**用户在场时**才做（第 6 步最后一条）。
- **能清干净是前提。** 第 1 步的两张快照**必须在装机之前拍**，拍晚了就证明不了「卸完回到原样」。
  往厂家系统里装东西：**用户 11-10 已同意装 ffmpeg（视频）、onnxruntime-gpu（人员检测）**；装了什么（包名、版本、
  怎么装的）记进 `系统改动.txt`，第 10 步照着撤。这两样以外的还要先问用户。
- **台式机改代码，现场只测。** 哪步不对，把现象和日志存下来，不在机器人上改代码。

日志统一放 `runs/field-logs/2026-11-10-newbot/`（台式机仓库里）。**开通码、证书、私钥不进日志、不截图、不贴群。**

2. `ssh robot@<Orin>`（厂家默认口令）。记进日志 `before-info.txt`：

**通过**：SSH 能登；把系统版本、ROS 有没有、ffmpeg / onnxruntime 有没有记下来（没有的那几样决定第 5、7 步要不要先问用户装东西）。

## 1. 装机前拍两张快照（**必须最先做**，10 分钟）

拍快照的那份 `footprint.sh` 先单独拷上去（放在家目录的临时目录，第 10 步删）：

```bash
# 台式机
scp deploy/footprint.sh robot@<Orin>:/home/robot/nexwar-test/footprint.sh
# Orin
cd ~ && sudo bash ~/nexwar-test/footprint.sh snapshot          # 落在 ~/runs/footprint/<时间>.txt
```

`footprint.sh` 只看 `/opt`、`/etc`、`/etc/systemd/system`、`/var/lib`、`/usr/local` 这几处。下面这些它看不到，
**另拍一张补充快照**（也只读）：

```bash
mkdir -p ~/runs/footprint/extra-before && cd ~/runs/footprint/extra-before
dpkg-query -W -f='${Package} ${Version}\n' | sort > dpkg.txt          # 系统包
python3 -m pip list 2>/dev/null | sort > pip-system.txt                # 系统 Python 的包
id robot > id.txt; getent group dialout systemd-journal > groups.txt    # 账号所在的组
ls -la /var/log/journal > journal-dir.txt 2>&1                          # 日志留不留盘
ls -la ~ > home.txt; du -sh ~ > home-du.txt                             # 家目录
systemctl list-unit-files --no-pager > units.txt
sudo crontab -l > crontab-root.txt 2>&1; crontab -l > crontab-robot.txt 2>&1
ip route > route.txt
```

把 `~/runs/footprint/` 整个拷回台式机日志目录（`scp -r`）。**机器人上那份也先留着**，第 10 步对完再删。

**通过**：快照文件存在，屏幕上 `snapshot` 没喊 8090 / 8091 端口被占。

## 2. 装我们的软件（30 分钟）

1. 台式机打包（master 最新，带离线轮子）：

   ```bash
   .venv/bin/python -m nexwar_patrol.cli release pack . ~/newbot-pkg --wheels dist/wheels-aarch64-py310
   ```

   抄下包目录名和 `content_sha256`，填进表里。`ls` 一眼包里没有 `refs/`、`dist/`。
2. 拷到 Orin：`scp -r ~/newbot-pkg/<包名> robot@<Orin>:/home/robot/nexwar-test/`。
3. 装（**先拔网或确认上不了外网**——联网的话 `install.sh` 会顺手 apt 装 `wireguard-tools`；
   上不了外网就只提示、不装。离线轮子用 `NEXWAR_PIP_ARGS`，见 `docs/装机清单.md`「一」）：

   ```bash
   sudo NEXWAR_PIP_ARGS='--no-index --find-links=/home/robot/nexwar-test/<包名>/wheels' \
     bash /home/robot/nexwar-test/<包名>/deploy/install.sh /home/robot/nexwar-test/<包名>
   ```

4. 按 `docs/装机清单.md`「二」逐条看 1/7–7/7。屏幕最后提示缺哪些系统件（ffmpeg / onnxruntime / dialout），
   **记下来，先不装**。

**通过**：7/7 都过，`/opt/nexwar/current` 指着刚装的这一版。

5. 填 `/etc/nexwar/env`：`NEXWAR_SN=<SN>`；`NEXWAR_HAL=sim` **先留着**（第 6 步再说）。

**通过**：`docs/装机清单.md`「三」六条全过（`selfcheck` 没有 FAIL）；网页上这台在线、遥测新鲜；

## 4. 开机和对时（20 分钟）

这台的系统如果用 chrony（多数是），我们只写 `/etc/chrony/conf.d/nexwar.conf` 一个片段（决策 61），不动厂家配置。

1. `chronyc sources -v`：站点那一行带 `*`；`timedatectl` 跟台式机差 1 秒以内。
2. **整机断电重启一次**（机器人是趴着的，重启不会站起来；用户在场再做）。起来以后：
   - `systemctl status nexwar_boot nexwar_agent`：都 active；`systemctl show -p NRestarts nexwar_agent` 是 0；
   - `journalctl -b -u nexwar_agent | head -30`：代理**等对完时**才起（不该看到 1970 年、TLS 失败重试）；
   - 网页上这台重新在线，记下从上电到在线用了多久。

**通过**：重启后不用任何手工操作就回到在线；钟差 1 秒以内。

## 10. 清干净（1 小时）

**先停我们的东西、先看再删。** 每一处删之前把要删的列表给用户看，用户说可以再删。

1. **站点上先把这台的东西取下来**（要留的日志、截图、静止数据已经在台式机日志目录里了）。
2. 停我们起的、没 enable 的：`sudo systemctl stop nexwar_persons nexwar_sidecar`。
3. **先看**（用拷上去的那份包里的卸载脚本，**别用 `/opt/nexwar/current` 底下那份**——它跑到一半会把自己删掉；
   `--agent-root` 指旁路的工作目录，脚本经那里的 FIFO 让旁路自己退）：

   ```bash
   sudo bash ~/nexwar-test/<包名>/deploy/uninstall.sh --dry-run --purge-agent-binary --agent-root /home/robot/nexwar_sidecar
   ```

   输出存日志，给用户看。
4. **真删**：去掉 `--dry-run` 再跑一次（默认就是彻底卸，包括 `/var/lib/nexwar`、`/etc/nexwar`、`/opt/nexwar`、
   我们所有的 systemd 单元、对时片段、日志留盘设置、特权执行器）。
5. **对快照**：

   ```bash
   cd ~ && sudo bash ~/nexwar-test/footprint.sh diff runs/footprint/<装机前那一份>
   ```

   新增、改动、消失三档都该回零。不是零的逐条抄进日志，一条条查。
6. **补充快照对一遍**：把第 1 步那几条命令输出到 `~/runs/footprint/extra-after/`，跟 `extra-before/` 逐个 `diff`。
   预期会有差的，按 `系统改动.txt` 撤：
   - `dpkg.txt` 多了包（ffmpeg / libsrt / wireguard-tools …）：**问用户**后 `sudo apt-get purge <包>`；
   - `pip-system.txt` 多了 onnxruntime-gpu：`sudo python3 -m pip uninstall onnxruntime-gpu`；
   - `id.txt` 多了组：`sudo gpasswd -d robot systemd-journal`（`dialout` 同理，原来没有才删）；
   - `journal-dir.txt`：原来没有 `/var/log/journal`、现在有 → 删掉它，`sudo systemctl restart systemd-journald`
     （不删的话系统会继续把日志长期留盘）。原来就有的不动。
7. **家目录**：`ls -la ~` 跟 `home.txt` 比，多出来的一般是：`~/nexwar-test/`（包、快照脚本、DIFOP 脚本、静止数据）、
   `~/nexwar_sidecar/`、`~/.nexwar/`（旁路令牌）、`~/.cache/pip`、编旁路用的 SDK 目录、`~/runs/`。
   **列给用户看，用户说可以再删**。`~/runs/footprint/` 最后删（它是证据，先确认台式机上有一份）。
8. **整机重启一次**：把控制权还给厂家（第 6 步那条）。重启后厂家 App 能连上、能操作（用户在场时试站起趴下）。
   重启后再跑一次第 6 小步的 `diff`，确认没有东西开机又冒出来。
9. **台式机这边**：
   - `nexwar_site --home ~/newbot-site revoke <编号>`，然后停测试站点（按记下的进程号），`~/newbot-site` 列给用户看后删；
   - `~/newbot-pkg`、`~/newbot-factory` 删掉（**`~/newbot-factory` 里有绑定信息**）；
   - 出厂台账里这一行留着，备注改成「测试机，已撤，2026-11-xx」；
   - 手机：App 里删掉这个测试站点。

**通过**：`footprint.sh diff` 回零；补充快照除了下面「收不掉的」以外没有差；家目录回到 `home.txt` 的样子；
厂家 App 重启后能控制机器人。

### 收不掉的（写进日志，让用户知道）

- **系统日志里我们服务的历史**（`journalctl -u nexwar_agent`）：**不删**（用户 11-10 定）。要清只能连厂家的日志一起清。
- **shell 历史**（`~/.bash_history`）：要清就整个清掉这几天的，到第 10 步时问用户。
- **删掉的文件在盘上的残留字节**：`rm` 不擦盘。机器要交给外人的话另外做填盘，一般不用。
- **厂家那一侧**：这张单子不发导航指令、不建图，厂家那边不会有我们的地图和路线；只有第 6 步站起趴下的指令（如果做了）。
