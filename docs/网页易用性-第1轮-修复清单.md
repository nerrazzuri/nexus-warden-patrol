# 网页易用性测试 第 1 轮 — 修复清单

来源：易用性测试报告（2026-11-07，站点 192.168.5.12:8520，账号 demo/gina/olga/vic）。153 条：P0 20、P1 87、P2 46。
修完一条打勾，写上提交号；不修的写原因。

## P0 上线前必须修

### 警情判断与值班

- [ ] **P0-01 警报原因写错**（总览、警报）— 电量 93–98% 时，标题却是 P1“低电量，返回途中停下”。真实原因是“地图未标原点、出发前检查没通过”，藏在中文开发者文案里。保安会照着“低电量”去处理。
- [ ] **P0-02 断线时仍显示“All clear”**（总览）— 连不上站点时，状态行仍是绿色“All clear”，布防标签消失，警报数显示成“?”，机器人状态是灰色的 Unknown。应改成醒目的“状态未知”。
- [ ] **P0-03 派狗被拒也提示成功**（地图）— 临时派狗被出发前检查拒绝，界面仍提示“B is on its way”，还额外产生一条误导性的 P1 警报。
- [ ] **P0-04 “已处理”一点就关闭 P1 警报**（总览、警报）— 没有确认，不能选处理结果（入侵、误报等，帮助里写的这个功能实际不存在），不能写备注，不能撤销。它和“我来处理”挨着、样式相同。误报统计也因此没有数据。
- [ ] **P0-05 保安值班流程走不通**（总览、地图、警报；角色：保安）— 点某条警报没有详情（原因、位置、视频、录像）；接手后没有下一步指引；不能从警报直接派狗，点地图派狗只显示“No robot on this map can be sent.”。
- [ ] **P0-06 停狗后恢复不了**（顶栏、机器人；角色：保安）— Stop all 后仍显示绿色“All clear”，没有“全部恢复”按钮，只能逐只进详情恢复。保安能停狗，但保安界面里没有任何恢复入口（服务端其实允许保安恢复）。
- [ ] **P0-07 录像链路没跑通**（录像）— 当天所有摄像头都是 0 段录像，警报里的“看录像”没有用，缩略图是黑的。录像页的播放、导出、保留没法验证。

### 布防与安防配置

- [ ] **P0-08 保存布防日程会立刻撤防**（布防时间）— 只画一个时段并保存，全站立刻变成撤防，没有任何提示。手动切换 Stay 有确认，这个影响更大的操作反而没有。
- [ ] **P0-09 没有防区也能临时撤防 4 小时**（授权与临时撤防、系统状态）— 一键开始，没有确认，没有地方选防区。系统状态页的确认框写着“选中的防区”，可那里根本没有选择控件。
- [ ] **P0-10 解绑没有真正断开机器狗**（机器人）— 解绑后旧连接一直没断；网页上重新登记同一个编号，不用激活就直接上线。界面说“会清除机器人数据”，但服务端不支持远程清除。
- [ ] **P0-11 去噪会误删真实障碍**（地图管理）— “点红圈保留”对真人点击无效，红圈被底图挡住，细柱子等真实障碍会被一起清掉。

### 数据丢失

- [ ] **P0-12 未保存就离开，改动静默丢失**（设置、布防时间、地图编辑器）— 设置页、布防时间页、地图编辑器都不提醒。设置页弹窗里的“保存”不是真保存，还要再点右上角的 Save。
- [ ] **P0-13 另存新版本时部分编辑没保存**（地图编辑器）— 地图编辑器里的命名区域、特殊地面、底图都没有存进新版本。
- [ ] **P0-14 换地图后巡逻路线全部丢失**（设置、机器人）— 导入新地图前不警告，导入后也不提示，巡逻路线和今日计划直接消失。
- [ ] **P0-15 地图版本删不掉**（地图管理）— 最新版本、正在使用的版本、回滚目标都不能删，总会留下一个删不掉的版本，回滚按钮还指向它。

### 多端可用性与稳定性

- [ ] **P0-16 手机上：无法退出、用户管理点不到**（手机/平板）— 用户菜单被隐藏，没法退出登录、切换语言、修改密码；用户表被截断，批准、禁用、删除按钮在屏幕外；没有汉堡菜单。
- [ ] **P0-17 平板和手机上看不到视频**（手机/平板、总览）— 1024 宽及以下，总览页的视频面板高度为 0。
- [ ] **P0-18 站点不稳定**（全站）— 服务端连接排队上限只有 5，几个人同时用就会断连。断连时样式加载失败，整页变成没有样式的 HTML；会话还会突然失效。
- [ ] **P0-19 系统页请求过多**（系统）— 页面放着不动时，5 秒内请求 /api/metrics 约 100 次，两组测试都复现了。

### 权限与界面一致性

- [ ] **P0-20 界面和服务端的权限对不上**（总览、警报、顶栏；角色：只读、保安）— 只读用户能看到“处理警报”按钮，点了才报错；保安能停狗却没有恢复入口；保安切换布防，两组测试的结论相反（一组成功、一组 403），需要开发确认保安到底该不该有这个权限。

## P1


### 全站

- [ ] **P1-01** 英文界面里大量夹着中文开发者文案和接口原话，有的还带文件路径、命令行、内部权限名（例如“viewer 没有 manage_accounts 权限”“此站点未安装特权执行器”）。建议：服务端只返回错误码，前端负责翻译成用户能看懂的话
- [ ] **P1-02** 菜单名称不统一：侧栏叫 Setup，帮助和提示里写成 Layout、Site layout、Admin → Overview。建议：统一叫法，提示里的页面名做成可点的链接
- [ ] **P1-03** 日期格式混用（mm/dd/yyyy 和 YYYY-MM-DD），时间混用 12 小时制和 24 小时制；多处日期能选到未来。建议：统一用 YYYY-MM-DD 和 24 小时制，并限制可选范围
- [ ] **P1-04** 浏览器标签标题永远是“Nexus Warden · Duty console”，开多个标签页时分不清。建议：标题改成“页面名 · Nexus Warden”，随语言切换
- [ ] **P1-05** 该确认的没确认：禁用用户、新激活码、允许自动派遣、机器狗软件回退、提前结束工程师账号、远程重启服务、删除例外日期、改用户角色（包括升为管理员）。建议：对不可逆或影响安防的操作统一加确认
- [ ] **P1-06** 按钮能点、点了才说做不到：回家、回待命点、自动定位、测试推送、网页升级、重启站点服务、机器狗软件回退。建议：条件不满足时置灰，并写明原因
- [ ] **P1-07** 操作结果的提示不准确：删除成功提示“Saved.”；批准用户成功了却报“Failed: network”；改完密码提示的是“会话已过期”。建议：提示要如实说明刚才发生了什么
- [ ] **P1-08** 页面变长后，侧边栏背景只到第一屏底部，下面是空白。建议：侧边栏改为固定定位，或者高度撑满
- [ ] **P1-09** 文件选择框是浏览器原生的“Choose File”样式；路线名等输入框只有 21px 高、没有样式。建议：统一表单控件样式

- [ ] **P1-11** 断流提示占 4 行，盖住画面中间；“0 秒前”和“画面丢失”自相矛盾；中英混杂。建议：改成角落里的一行提示，保留最后一帧画面
- [ ] **P1-12** A、B 位置完全重叠，地图上只看得到一个；改名后两个标签叠在一起，显示成“巡逻B一号”。建议：位置重叠时把标签错开，或合并显示
- [ ] **P1-13** 点总览警报列表里的某一条没有反应；警报页的“Handle it”只会跳回总览，不定位到这条警报。建议：做一个警报详情页
- [ ] **P1-14** “今日巡逻”直接显示中文技术描述，被截断，“Not finished”不说原因。建议：改写成用户能看懂的话，悬停显示全文

### 实时

- [ ] **P1-15** 两路视频只占上半屏，下半屏空着；放大后的视频在手机上反而更小。建议：视频按可用空间放大

### 地图

- [ ] **P1-16** 临时路线可以落在墙外或没扫描过的地方，要按“开始”才报中文错误；派出后看不到路线和进度。建议：落点时就检查；派出后在地图上画出路线和进度
- [ ] **P1-17** 右侧显示“Needs action · 0”，可警报记录里还有未处理的警报。建议：两处数据保持一致

### 警报

- [ ] **P1-18** 顶部“For [30 min] Start alert test”看不懂；点了以后不会产生测试警报，只出现一条横幅。建议：挪到系统页，并说明用途

- [ ] **P1-20**（保安） 交班留言：自己刚写的显示成“上一班的留言”，写了以后不能改、不能删。建议：区分“我写的”和“上一班的”，允许修改
- [ ] **P1-21**（只读） 只读用户能看到“测试模式”横幅，但看不懂，也没有相关操作。建议：改成一句简短说明

### 录像

- [ ] **P1-22** 控制按钮折成两行，“上一段”“下一段”被拆开；按角色隐藏按钮后留下空位。建议：一行排列，隐藏后重新排版

### 机器人

- [ ] **P1-23** 刚添加、还没激活的机器人显示成红色“Offline”卡片，看起来像故障；说明里写的“等待加入”区域并不存在。建议：单独放一个“等待加入”分组

- [ ] **P1-25** 机器人编号格式错误时，只有浏览器的原生提示；编号重复时报“A 已登记且未吊销;先 revoke”。建议：在输入框下写明格式，报错改成“A 已存在，请先解绑”
- [ ] **P1-26** “允许自动派遣”点一下立即切换，不确认，也不解释“自动”是什么意思；状态文案中英混杂。建议：加说明和确认
- [ ] **P1-27** 回家、回待命点、自动定位在条件不满足时仍可点，点了才报红色中文错误，还把下面的内容挤下去。建议：置灰并写明原因
- [ ] **P1-28** 站立、趴下、蹲下之后看不到当前姿态；“停止当前任务”单独一行靠右，机器人空闲时也能点。建议：显示当前姿态；空闲时置灰
- [ ] **P1-29** 解绑后，B 的历史录像和记录在各页面都看不到了。建议：保留一个“已解绑”的历史视图
- [ ] **P1-30**（经理） 说明文字写着“可以改名、解绑”，详情里还提示“去 Layout 添加路线”，而经理做不了这些，也进不去那个页面。建议：按角色显示对应的说明

- [ ] **P1-31** 已画好的禁区、防区不能选中、不能拖顶点、不能改名，只能删掉重画。建议：支持选中、编辑顶点、改名
- [ ] **P1-32** 删除一个禁区要 5 步：删除、确认、保存、勾选声明、再输密码；确认框写着“确认后生效”，其实还要再保存。建议：安全确认保留，步骤合并到一个弹窗里
- [ ] **P1-33** “擦除区域”不会擦掉已画的禁区，而是新建一块“机器人永不进入”区域，还要求填名字。建议：改名为“标记不可通行区”
- [ ] **P1-34** 开始编辑时“未保存”提示条出现，地图下移 46px，保存后又弹回去；正在画图时容易点歪。建议：提示条不要占布局高度
- [ ] **P1-35** 弹窗里一个“保存”，右上角又一个“Save”，含义不同。建议：弹窗里的按钮改叫“确定”，或者合并成一个
- [ ] **P1-36** 点第一个点不能闭合图形，反而多加一个点；名字弹窗按回车不能提交。建议：点第一个点自动闭合；回车提交
- [ ] **P1-37** 减速区限速：填非法值时“保存”变灰，但不说允许范围（0.1–5）；填 0.05（低于最小值）反而能保存。建议：显示允许范围，修正校验
- [ ] **P1-38** “忽略人员区”放在“机器人不会进入”的禁区标签下，概念放错了地方。建议：移到防区标签，或单独分组
- [ ] **P1-39** 路线可以穿墙、穿禁区，要到保存时才报错，报错是中文；路线名不能用中文。建议：画的时候就实时标红；允许中文显示名
- [ ] **P1-40** 从防区生成路线时，东区生成失败，提示是“防区跟最大可走区域不连着(还没设待命点)…”。建议：改写成用户能看懂的话，并给出“去设待命点”的入口
- [ ] **P1-41** 编辑路线时右侧面板很长，地图下方大片空白；“保存”在页面最上面，“放弃”在最下面。建议：面板内部滚动，两个按钮放在一起并固定
- [ ] **P1-42** 摄像头的防区要手动输入，不能从已有防区里选；要填 ONVIF、RTSP；复选框样式坏掉；说明写着先放置，实际先弹表单。建议：防区改下拉框；术语加说明；先放置再填表
- [ ] **P1-43** 摄像头添加后立即保存，其他标签都要点右上角的 Save，保存方式不一致。建议：统一保存方式
- [ ] **P1-44** “历史”只能恢复到存过的版本，回不到最初的空状态；版本摘要是中文（“5 块”“1 台”）；有未保存的改动时，“历史”按钮会消失。建议：加入“初始”版本，摘要翻译成英文，按钮常驻

### 地图管理

- [ ] **P1-45** 发布时要先选机器人、输密码、点发布，然后才报“禁区尚未确认”（中文），而且没有去确认的链接。建议：发布前就检查，并给出跳转链接
- [ ] **P1-46** 发布弹窗默认不勾选任何机器人，“发布”是灰的但不说原因；“没有原点也发布”这个选项看起来像一台机器人。建议：默认勾选在线的机器人；把这个选项单独分组
- [ ] **P1-47** 密码要求不一致：发布要密码，回滚和删除版本（写着“无法撤销”）反而不要。建议：统一高风险操作的密码要求
- [ ] **P1-48** 对比时两个版本叫“A”“B”，和机器人 A、B 同名；差异只用几个蓝点表示，几乎看不见；不能放大。建议：用版本号命名，差异高亮，支持滑动对比
- [ ] **P1-49** 版本备注最多 200 字，超出部分被静默截断，保存后没有提示；长备注把设置页的下拉框撑出屏幕。建议：显示字数，有保存反馈，下拉框里截断显示
- [ ] **P1-50** 版本卡上满是技术信息（bag:raw-bag、super-lio、Loop closure）；自动备注是中文；作者显示为“denoise”“edit”，而不是操作人。建议：技术信息折叠起来，作者显示真实操作人

### 地图编辑器

- [ ] **P1-51** 两个“橡皮擦”：编辑器的“Eraser”和设置页的“Erase a region”名字很像，作用完全不同。建议：分别命名，并各自说明用途
- [ ] **P1-52** 擦除只显示为绿色覆盖层，看不出擦完的样子；擦除、障碍、特殊地面在图例里都没有。建议：预览擦除后的效果，补全图例
- [ ] **P1-53** 方框模式按住拖动没有反应；一打开编辑器就默认选中橡皮擦。建议：支持拖动画框；默认不选任何工具
- [ ] **P1-54** 底图上传后在地图上看不到；数字框里出现“12.641000000000002”这样的浮点误差。建议：修复底图显示，数值四舍五入
- [ ] **P1-55** 保存后仍停在 v7 的编辑页，不提示新版本号，也没有“去发布”的入口；保存确认里的面积和版本备注里的数字对不上。建议：保存后跳到新版本，并显示一致的数字

- [ ] **P1-56** “帮它定位”里最醒目的主按钮是“Go here”（派狗过去），很容易误点；页面上有两套操作说明；设完位置看不到定位进度。建议：定位模式下把“设定位置”作为主按钮，设完显示进度

### 布防时间

- [ ] **P1-57** 布防时间页还塞着守卫值勤、报警设备（手输坐标）、班次、警笛设置。建议：拆成几个页面，报警设备在地图上点选位置

- [ ] **P1-59** 时间轴：单击没有反应，也不提示要拖动；和已有时段重叠时静默忽略；不能拖边缘调整长度；没有图例说明哪个颜色代表布防。建议：加提示和图例，支持调整长度
- [ ] **P1-60** 例外日期能选过去的日期；结束早于开始要提交后才报中文错误；错误提示框盖住了备注输入框。建议：实时校验，提示放在不挡内容的位置
