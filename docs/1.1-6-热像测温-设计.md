# 1.1-6 热像测温：找起火、过热（设计）

11-28 定。用户：「继续把所有1.1功能都做了」。依据：决定 72（10-27 用户：热成像要在界面上，**用来夜里找人、发现起火和过热**；「起火、过热」是保安的第四类事；温度那一半等实物接 ISAPI）。

## 已经有的

- 热像当第三路相机（W40）：`/etc/nexwar/cameras.json` 配 RTSP 地址；能看、能录、值班页一键换热像。
- 热像镜头被挡（W46）：画面糊了报 P2。
- 告警分类早留好了 `fire` 这一类（保安看，跟入侵一样急）：网页、App 的报警列表、铃声、结论按钮都已经把它当入侵处理，只是一直没有 kind 归进来。

## 定下来的

| 项 | 定的 |
|---|---|
| 温度从哪来 | **热像机自己算**。装机时在热像的网页上设一条全画面的测温规则；机器人每 5 秒用海康 ISAPI 问一次这条规则的最高温度（HTTP Digest，账号口令跟录像那一路同一套，只在内存里） |
| 为什么不自己算 | 我们拿到的视频流是伪彩色画面，没有温度；要温度只能问热像机本身 |
| 读回来的格式 | JSON、XML 都认。所有叫 `maxTemperature` 的数取最大的，不认死结构（各家固件的嵌套不一样） |
| 接口路径 | 缺省 `/ISAPI/Thermal/channels/2/thermometry/1/rulesTemperatureInfo?format=json`。**没拿实物核过**，所以可配 |
| 开不开 | `cameras.json` 热像那一路写了 `thermometry` 才测温；不写和以前一样 |
| 两条线 | 高温线缺省 **70 °C** → P2「热像发现高温点」；起火线缺省 **150 °C** → P1「热像发现疑似起火」。人体表面 30 多度、晒过的车顶 60 多度，所以高温线不能太低。两条线都能配（`hot_c`、`fire_c`），到现场按实物标 |
| 防误报 | 连着两次（10 秒）过线才报。先报了高温、后来到了起火线，再报一次起火（升级成 P1） |
| 归哪类 | 起火、高温都归 `fire`：给保安看，跟入侵一样响铃、一样有「有人 / 误报 / 处理了」 |
| 降回去了 | 连着三次低于高温线 5 °C 以上，机器人报回落。站点**不自己关**（起火、过热要人看过），只在现场记下回落时的温度和最高温度 |
| 问不到 | 连着 6 次（30 秒）问不到 → 给管理员 P2「热像量不了温度」：看测温规则、账号。问到了自己解决 |
| 告警里写什么 | 最高温度、过的是哪条线；起火那条写「真起火按消防流程报警、叫人，不要等机器人」 |

`cameras.json` 例子（口令打码）：

```json
{"thermal": {"url": "rtsp://<账号>:<口令>@192.168.10.64:554/Streaming/Channels/201",
             "thermometry": {"hot_c": 70, "fire_c": 150}}}
```

写错了（线反了、路径不是 `/ISAPI/` 开头、端口不对、多了不认的字段、写在别的相机上）代理不起，说清楚哪里错。

## 没做、以后做

- **巡检点量温度**（到了某个点，量那一处的温度，超了报）：要在每个点上配一块测温区域，或者转云台对准。等实物和第一个要量温度的客户。
- **哪里热**：现在只说多少度，不说画面上哪一块。ISAPI 有的固件会回最高温那个点的坐标，核过实物再在画面上标。
- 机器人看到起火自己去现场、自己开警灯。现在只报警，保安决定。
- 模拟器里的热像温度（模拟器的热像那一路没有温度）。

## 要上真机核的

- 热像固件的 ISAPI 路径、回的字段（`maxTemperature` 在不在、单位是不是摄氏度）。
- 全画面测温规则怎么设，晚上、雨天最高温度平时是多少（定高温线）。
- 每 5 秒问一次对热像机、对网络有没有影响。

## 代码

- 机器人：`thermo.py`（`max_temperature`、`isapi_reader`、`ThermoWatch`）；`video_push.load_cameras` 认 `thermometry`；`runtime.attach_thermo`（后台问，不卡主循环）；`main.py` 写了才接上。
- 事件：`thermal_hot`（`level` = `hot` / `fire`）、`thermal_normal`、`thermometry_failed`、`thermometry_ok`。
- 站点：告警 `thermal_fire`（P1）、`thermal_overheat`（P2），都归 `fire`；`thermometry_failed`（P2，管理员）。错误码 0x080E–0x0810。
- 测试：`robot-agent/tests/test_thermo.py`、`site-node/tests/test_site_thermal.py`。
