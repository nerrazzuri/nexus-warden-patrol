- 人流大：开业后月均约 64 万人次，一天约两万人。27 号是星期四。
- 11 月底是东北季风期，下午常有雷阵雨。

### 这些地方先想好怎么处理

| 风险 | 怎么办 |
|---|---|
| 湖、水景 | 出图后**第一件事**画**硬禁区**（水体），离水边留 2 m 以上；没画完之前不让机器人自己走 |
| 得来速车道、停车场、路面 | 画禁行区；机器人**不过车道**。扫图时也不上车道 |
| 跟地砖齐平的草坪 | 建图认不出来，要不让走就画禁行区 |
| 台阶、坡口、路沿 | 巡逻要走的台阶、坡口，扫图时都开上去一次（不然会当成路沿） |
| 露天座位（桌椅会被挪动）、人多 | 扫图挑人少的时候；人多的地方**走完回头再走一遍**；**收尾别停在人多的地方** |
| 玻璃门、玻璃橱窗 | 雷达看玻璃不准，扫图时离玻璃 1 m 以上慢走；巡逻路线别贴着玻璃 |
| 大片空地（足球场一类） | 特征少，定位容易漂。路线尽量沿着有建筑、有柱子的地方 |
| 阳光直射、明暗反差 | 相机看人会不稳。演示「看见人」挑有遮阳的地方 |
| 下雨 | 下雨不出机器人。重要的演示尽量放上午 |
| 小孩、路人围观 | 布防时谁走近都会报警、会跟。**演示时只在划好的一小块防区布防**，用我们自己的人当「入侵者」，别的地方撤防 |
| 拍到顾客 | 先跟商场确认可以拍；录像、照片留在站点，不出现场 |

## 二、当天顺序

1. **开机**：机器人自己准备约 2 分钟。网页「机器人」卡片变在线、没有「Nav2 不可用」。
2. **开机检查**：机器人详情看电量、定位；「诊断」快照里服务都是 active。
3. **扫图**（管理员登录会弹「开始建图」）：
   - 先开始，**原地站稳 5 秒再走**；
   - 向导里写着这个包多大、盘还剩多少，不到 20 GB 会提醒；
   - 停之前先让机器人站稳；原地没走就点结束会先提醒；
   - 出图失败会写真正的原因，点「详情」看日志（截图留给我们）。
4. **改图**：「地图 → 编辑」：先画**湖、水景的硬禁区**，再画车道、草坪禁行区，擦残影 → 保存草稿 → 发布 → 下发到机器人。
5. **标原点、待命点**。
6. **布防向导**：选防区 → 路线（自动生成的路线现在会画在图上，看一眼它走哪）→ 什么时候 → 谁巡逻 → 确认。
7. **演示巡逻**：机器人详情选路线 →「开始巡逻」。平时巡逻慢（0.6 m/s）、有情况快（1.0 m/s），演示时可以讲。
8. **演示看见人**（我们的人当入侵者）：
   - 网页值守页：看到人的那一路相机自动放大；不在值守页时右下角卡片带实时画面；
   - 手机：横屏整屏实时画面，右边「我来处理 / 静音 2 分钟 / 详情」；
   - 机器人会跟、保持 4–5 m；人太近会退；身后有东西退不了会原地站定；人离开防区不再跟。告警里都写着。
   - 喇叭、警笛太吵：App 机器人页「静音（Mute）」（下次布防自动解除）。
9. **遥控演示**：手机横屏遥控。松手后**倒数 30 秒**才回待命点，想留在原地点「留在这里（Stay here）」：
   之后 **10 分钟内值守不会自动派它去巡逻**（提示里写到几点），手动派照常。倒数期间值守也不派（以前布防时一松手就被派走）。
10. **收尾**：撤防（见人的警灯、警笛会当场关）→ 回原点 → 趴下。
    巡逻、去某点、跟人的时候不让趴下（会写「先原地停下」），先「原地停下」再趴。

## 三、出问题时（先看这里）

| 现象 | 先看哪里 | 怎么处理 |
|---|---|---|
| 机器人卡片离线 | 卡片上写的原因 | 等 2 分钟（开机还没好）；还不行「诊断 → 重启服务（Restart service）」，再不行「重启机器人（Restart robot）」 |
| 写「控制权在别人手里」 | 厂家遥控器 / App 是不是开着 | 关掉厂家遥控器，等 1 分钟 |
| 写「Nav2 不可用」 | 诊断快照 | Nav2 自己会重来；超过 3 分钟还不行「重启服务 → Nav2」 |
| 定位不可信 | 机器人详情 | 「自动定位（Auto-localize）」；不行就在地图上设位置，原地静止 10 秒。开阔地多试几次 |
| 派巡逻被拒 | 弹出的原因（会写在忙什么、哪段路太窄、差多少） | 照原因处理；路太窄就挪路线点 |
| 走着停下「卡住了，请遥控接管」 | — | 它自己已经试过退、绕。手机遥控开出来，再派一次；记下地点 |
| 没有画面 | 机器人页画面那里写的原因 | 等 10 秒（开流要几秒）；切一下前、后相机；还不行「诊断 → 重启服务」选视频那个服务 |
| 看见人没报警 | 有没有布防？人员检测开没开？ | 布防、开人员检测（前一晚第 3 条） |
| 手机没收到推送 | 网页「站点运维 → 发送测试推送」 | 手机通知权限、后台运行；App 开着时看值守页 |
| 出图失败 | 向导里那一句原因 +「详情」 | 截图；能重来就再扫一次（录包还在机器人上） |
| 升级被拒 | 升级页写在忙什么 | 等它忙完（巡逻、建图、充电中）再装 |
| 盘满 | 诊断快照、建图向导 | 旧录包会先删最旧的；还不够先别录 |
| 时间不对 | 诊断快照 | 「立即对时」 |
| 自己看不出原因 | — | 手机 App「报问题（Report a problem）」（登录页也有）→ 拿到编号 `NW-MMDD-XXXX` → 发给我们；**现场先换个办法接着演示**，别停在那里查 |

**在客户面前**：出问题先用「中止并回原点（Stop and return home）」或手机遥控把机器人开到安全的地方，再处理。**不要当着客户 SSH、敲命令。**
