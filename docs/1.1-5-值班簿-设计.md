# 1.1-5 电子值班簿 + 事件报告（设计）

11-28 定。用户：「继续把所有1.1功能都做了」。

## 为什么要

马来西亚的保安公司按惯例都有一本 **OB（Occurrence Book）**：上岗、下岗、巡查、访客、事件、交班，什么都按时间写进去，写错了不涂改、另写一条更正。客户审计、出了事报警都要看它。现在保安一边在我们的 App 上处理报警，一边还得在纸上再抄一遍。

出了事以后还要一份 **事件报告**（Incident Report）交给客户或者警方：什么时候报的、谁几点确认、几点到场、做了什么、怎么结的、照片。

## 已经有的

- 交班留言（W44）：只追加，一条 500 字。
- 报警的经过：确认、到场、喊话、警灯、关闭和结论（W44、W74）。
- 报表页：按天的数字，导出 PDF 就是浏览器打印（W44 第二期）。

## 定下来的

### 值班簿

| 项 | 定的 |
|---|---|
| 一本里有什么 | **保安写的**加上**站点自己记的**，按时间排在一起。站点记的有：P1 报警和给保安看的 P2（报了、谁确认、谁关、结论）、机器人巡检的每一趟（结果、几张照片）、外部报警器的事件、交班留言 |
| 站点记的怎么来 | 读的时候从各自的表里拼，不另存一份（不会两边对不上） |
| 保安写的类别 | 上岗、下岗、巡查、事件、访客、交班、维修、观察、其他 |
| 能不能改 | **不能改、不能删**（纸质 OB 的规矩）。写错了点「更正」另写一条，指向被更正的那条；原来那条划掉，写「已由 #n 更正」 |
| 补记 | 时间可以往前写，最多 24 小时（当场忘了写）；不能写到将来。写的时刻另记一份 |
| 一条多长 | 1–1000 字 |
| 跟报警连上 | 报警详情里「写进值班簿」：类别默认「事件」，带上报警号；那条报警的事件报告里会列出来 |
| 谁能写 | 能处理报警的（保安、管理员、经理，`handle_alerts`）。只读账号能看。作者取登录账号 |
| 网页在哪 | 记录与录像 → 「值班簿」（在交班留言旁边）：按天看、只看手写的 / 只看站点记的、左边写一条 |
| App 在哪 | 现场 → 记录 → 「值班簿」：按天翻、只看手写的、右下角「写一条」、每条「更正」 |
| 打印 | 「打印 / PDF」出一页能打印的：表格 + 底下交班人、接班人、主管三个签名栏 |

### 事件报告

| 项 | 定的 |
|---|---|
| 一页里有什么 | 站点、级别、事件、说明、机器人、报警时间、状态和结论、编号、最后位置；**经过**（报警、最后一次报、确认、保安到场、开警灯 / 喊话、值班簿里关于它的几条、关闭）；**照片**（那台机器人从报警前 1 分钟到关闭后 10 分钟拍的，最多 8 张，直接嵌进页面）；报告人、主管签名栏 |
| 网页 | 报警详情「事件报告」新开一页，点「打印 / 存成 PDF」 |
| App | 报警详情「分享事件报告」：交给系统的分享面板（邮件、WhatsApp、网盘），收到的人用浏览器打开就能存成 PDF |
| 审计 | 打开报告、打印值班簿都进审计（照片是个人数据） |

### 为什么不是站点直接出 PDF

站点上没有 PDF 库。要出中文 PDF 就得把中文字体嵌进去：包大几十 MB，字体授权也要跟着走。报表页已经用「浏览器打印」出 PDF，这里照这个做：站点出一页**自带样式和照片的网页**，浏览器打印成 PDF，中文、照片都对。

## 没做、以后做

- 站点直接生成 PDF 附件（比如每天定时发给客户的邮箱）。要做的话，在站点上装一个无头浏览器来转。
- 保安签名（手写签名、工号）。现在打印出来手签。
- 值班簿按班次（早班 / 晚班）分页。现在按自然日。
- 访客登记做成表格（姓名、证件、车牌、进出时间）。现在是「访客」这一类的一段文字。

## 代码

- 站点：`ob.py`（`OccurrenceBook`、`book_html`、`incident_report`、`report_html`）；表 `ob_entries`；
  接口 `GET|POST /api/ob`、`GET /api/ob/print`、`GET /api/alerts/<key>/report`。
- 网页：`obpage.tsx`（记录与录像的第五个标签）；`incident.tsx` 的「事件报告」按钮。
- App：`site_ob.dart`（`OccurrenceBookPage`、`writeOccurrence`、`shareIncidentReport`）；现场目录多一行；
  报警详情的「分享事件报告」「写进值班簿」。
- 测试：`site-node/tests/test_site_ob.py`、`web/console/src/obpage.test.tsx`、`mobile/test/site_ob_test.dart`。

## 外审 1.1 第 1 轮改的

- 更正跟着原来那条走：没写报警号、机器人的，用原来那条的（App 更正时不传报警号，事件报告里原来只有错的那条）。
- 事件报告里写错的那条标「已由 #n 更正」，更正的标「更正 #n」。
- 已经被更正过的那条不能再更正（要改就更正最新的那条），一条只有一个更正。
