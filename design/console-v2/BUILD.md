## 分期
1. 页框：顶栏（品牌、站点、值班 / 记录与录像 / 现场设置、布防状态、机器人在线、未处理数、时间、账号菜单、全部急停）；
   现场设置左栏 日常[概况, 机器人, 人员] 现场[布置, 布防与巡逻, 授权] 记录[报告] 高级[维护]；
   保安页深色、现场设置浅色；英文默认；角色可见范围按 HANDOFF。
2. 值班 V4 正常：左事件队列 + 交班留言；中 状态头 + 地图（全部/巡逻路线/防区/摄像头）+ 画面（单/双/四/监控墙）；右 机器人 + 今晚巡逻 + 最近活动；底 整班时间轴。
3. 值班 V4 告警：这件事（画面 + 地图 + 步骤条 + 派机器人 / 现场警示 / 通知 + 结论）；多告警；只读看进度；经理不派不遥控。
4. 保安补的：单台机器人控制（G-robot）、派去看一眼、临时路线（G-route）、急停后（G-estop）、1366×768（G-compact）、开班检查（G-check）。
5. 记录与录像（G-records、G-playback）。
6. 现场设置各页：概况（S-home；经理只读 M-home）、机器人（R-A/R-A2；经理 M-robot）、人员（S-users）、布置（S-layout）、
   布防与巡逻（S-arming）、授权（S-access）、报告（S-reports + 操作记录 S-log）、维护（S-system：升级、地图、定位、诊断、站点）。
7. 没画的：全站报警条、跟随目标状态、报警演练、账号菜单、连不上提示、开站清单/帮助、各页头面板 —— impeccable。
8. 后端补：派前电量估算、派去看一眼、临时路线、巡逻电量线、录像保留/跳时间、经理概况数据、机器人设置清单。
9. 英文术语按 en/dict.json 换掉 i18n.ts 里口语的；对照 48 项逐条打勾。
