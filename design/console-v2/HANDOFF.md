## 用户定下的规则（写代码必须照做）
1. **默认语言英文**，中文第二。英文用专业术语、不口语（见 dict.json；现有 i18n.ts 里 "Someone is there" "Help it localize" "Handled" "Stop all" 等要换）。
2. 界面叫「机器人 / robot」，不叫狗。
3. 保安页（值班、记录与录像）深色；现场设置（管理）浅色。
4. 标识语言（ISO 7010）：红圈 = P1/确认有人/危险操作；黄三角 = 提醒/P2；绿方块 = 正常；蓝圆 = 要你批准。蓝底只用于选中和每屏唯一主操作。2px 圆角，Barlow 字体。不堆卡片、不嵌套卡片、不用 unicode 字符当图标、不弹窗（同一页框里切换）。
5. 同排按钮等宽；角色少了功能时**不放灰掉的按钮**，用状态说明/更多信息填位，不能显得简陋。
6. **老网页的功能一个都不能丢**：画布上「老网页功能 → 新稿对照」（boards/P-parity.dc.html）48 项，「只画了一部分 / 还没画」的照老功能实现，排版沿用同一套。

## 结构
- 顶部：值班 Monitoring / 记录与录像 Events & Recordings / 现场设置 Site Setup；右边布防状态、机器人在线、未处理数、时间、账号、全部急停 E-STOP ALL。
- 值班（V4）：左事件队列 + 交班留言；中间 正常=地图+画面 / 告警=这件事（画面+地图+步骤+三组操作：派机器人 / 现场警示（A 的喇叭和警灯）/ 通知）；右机器人+今晚巡逻+最近活动；底部整班时间轴（点任意时刻看录像）。
- 保安补的：派去看一眼（地图上点 → 最近机器人去，看完接着巡逻或回待命点）、临时路线（按顺序点，只走一次）、单台机器人控制（右栏「详情」进入，云台/镜头/雨刷/喊话/警灯/停下/回待命/派路线/姿态/重新定位）、全部急停后（全部恢复…）、历史回放、多告警、1366×768。
- 现场设置左栏：日常[概况, 机器人, 人员] 现场[布置, 布防与巡逻, 授权] 记录[报告] 高级[维护]。

## 四种角色（按现有 shell.tsx pageAllowed / model.ts）
- 管理员：全部。工程师（临时）= 管理员去掉人员。
- 保安：值班全部操作（派遣、遥控、警示、处理、急停、布防）；没有现场设置。
- 经理：处理报警、急停、布防/日程、派巡逻；不能派机器人去报警点、不能遥控/警示。现场设置只有 **概况（只读，新开，用户 11-15 决定）**、机器人（只看 + 派巡逻）、布防与巡逻、报告。**经理保留急停**（用户确认）。
- 只读：只能看，没有急停，告警页显示「谁在处理 / 机器人 / 结论」进度。

## 后端要新增/核对的（稿里用到、现在可能没有）
- 派机器人前按电量算来回够不够（告警页「A 28%，来回约用 6%，够」）
- 派去看一眼：任意地图点 + 看完后动作（接着巡逻 / 回待命点）+ 不产生报警
- 临时路线：多点、只跑一次、不保存、不可达点预检
- 巡逻电量线（低于则回充，另一台接上）
- 录像「保留这段」（超过保留期不删）、跳到时间
- 经理概况的数据：24 小时报警+处理人+结论、管理员待办的进度（等批准 / 已看到）、值班人员与交班留言
- 机器人设置清单：续证书、发激活码、对时、清理存储、改参数、诊断包、重启巡逻程序/机器人、解绑（要密码）
