# 手机 App 重新设计（V2）交付说明

用户 11-15 已批准这套稿（「手机的设计非常好」）。结构 B「现在 / 现场」，跟网页 V4 是同一套视觉。

## 文件
- boards/*.dc.html：每页静态稿，中文版和 -en 英文版各一份（浏览器直接打开）
- png/*.png：每页截图，390×844（遥控页是横屏 844×390）
- gen/：生成脚本。ac.py 存色值和组件，now/now2.py 是「现在」页，site.py 是「现场」和进入页，parity.py 是对照表，en.py + app_dict.json 生成英文版
- 设计依据：/DESIGN.md、.impeccable/surfaces/mobile-lib.md（direction contract）
- 线上画布：https://claude.ai/artifact/UcgpLJUYn5GiziLxWPdbpp（App 的稿从 y≈20000 往下）

## 规则（跟网页一致）
- 默认语言英文（正式用语），中文第二。英文术语跟网页 design/console-v2/en/dict.json 一模一样，App 新增的词在 gen/app_dict.json。要修的已知不一致：App 现在用 Handled / Stop all，要改成 Resolved / E-STOP ALL / Take ownership；alert_titles.g.dart 缺 backup_requested
- 主题分开：「现在」页深色，「现场」设置类页浅色，进入页深色。设置里外观可选：按页面 / 深色 / 浅色
- 颜色只有四种意思：红圈 = P1、危险、急停；琥珀三角 = 警告；绿方块 = 正常；蓝 = 主操作和选中
- 「现在」页右下角大红方块「全部急停」（拇指区）；「现场」页顶栏放小红「急停」
- 不用弹窗（只有保护数据的确认例外，比如解绑、重启要再输密码）。同一行的按钮等宽。角色没有的功能直接不显示，不放灰按钮
- 遥控只能横屏，离开遥控页机器人就停
- 四个角色（管理员、保安、经理、只读）各自的页都要完整：经理能看、能派巡逻、能停下、能急停，不能遥控、喊话、开警灯、转云台；只读只能看
