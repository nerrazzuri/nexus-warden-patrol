# 手机 App V2 施工记录（redesign/app-v2 分支）

依据 design/app-v2/README.md（规则 + 58 项对照表）、boards/*.dc.html、.impeccable/surfaces/mobile-lib.md。
做法跟网页一样：分期、每期提交、每期更新 PARITY（对照表的「状态」列改成 已做 / 部分 + 原因）；全部做完送 codex 外审到没有 Important。

## 分期
1. 外壳：顶栏（站点名 · 布防状态 · 时钟）+「现在 | 现场」两段开关；「现在」深色、右下角拇指区「全部急停」；「现场」浅色目录（按角色四套），目录项先接到老页面；进入页先沿用。老的五栏底部导航删掉。
2. 「现在」页（N-normal / N-nomap / N-mgr / V-now）：事件条或一切正常、一路画面（前 / 后 / 热像）、机器人格、小地图、今晚巡逻、设备与运营、交班留言、最新活动、底部「有新版本」。
3. 这件事（N-alarm 全屏来报警、N-incident、N-multi、N-dispatch 派去看一眼、N-refuse 派单被拒、N-estop 急停后、N-ring）。
4. 机器人控制（N-robot、M-robot）+ 遥控横屏沿用 + 机器人列表 / 机器人设置 / 添加机器人（S-robots、S-robot-set、S-add）。
5. 现场各页按稿重排：概况（S-home / S-home-m）、人员、布防与巡逻、地图与布置（S-layout、S-zones、S-routes、S-route 临时路线、S-points）、记录（S-alarms、S-alarm-rec、S-runs、S-video、S-notes）、地图管理与建图（S-maps、S-wizard）、站点体检、软件升级、设置、使用教程 / 报问题、经理 / 只读目录（S-mgr、S-viewer）。
6. 进入页（E-sites、E-login、E-add、E-register）。
7. 后端补齐 + 用词：Handled → Resolved、Stop all → E-STOP ALL、Take ownership；alert_titles.g.dart 补 backup_requested；自动驱离分级状态 + 结束驱离、派单被拒原因、急停没确认再发、App 自更新提示、交班留言、报警演练 —— 照网页已有接口。
8. 「部分 / 没画」4 项照老功能：跟随时看不到人、建图向导其余步、建图预览、我在现场监护。
9. 逐条过 58 项、截图核对、外审。

## 规矩（HANDOFF 同款）
- 英文默认、正式用语，词跟 design/console-v2/en/dict.json + gen/app_dict.json 一致；中文第二。
- 四种颜色各一个意思；角色没有的功能不显示；同一行按钮等宽；不弹窗（再输密码除外）；遥控只横屏。
- 真机测试那边（易用性测试）按期知会。

## 进展
- 第 1 期（11-15）外壳：顶栏 + 「现在 | 现场」两段开关、深色 / 浅色两层、右下角「全部急停」方块、浅色页顶栏小「急停」、四套目录；老五栏底部导航删掉。
- 第 2 期（11-15）「现在」页 NowPage（lib/ui/nw/nw_now.dart）：P1 红框事件条（我来处理 / 打开这件事、别人接手只剩打开）、几件同时开着一行、急停卡 +「全部恢复」就地确认、没地图一条、全场正常 / 有机器人急停离线时琥珀「要看一下」、一路画面默认不播、机器人两格一行、小地图 + 派去看一眼 / 临时路线 / 全屏地图、今晚巡逻、设备与运营、交班留言、最新活动、底部「有新版本」一条。
  - 外壳「现在」段的 P1 计数改由「现在」页读报警时更新（以前只靠机器人列表页的实时连接）；横屏时浅色页的 P1 红条并进顶栏一个红块，「现在」页右边给急停方块让出一列。
  - 目录照稿：保安、只读没有「日常」（机器人和地图在「现在」页上），经理的「现场」只有布防与巡逻。
- 第 3 期（11-15）「这件事」页（lib/ui/site_alert_scene.dart 重写，深色）：页头（几点发现 · 已过多久、标题 + P1、在哪、人距离 / 驱离第几级、谁在处理 / 没人接手多久 +「我来处理」、跟随中 / 看不到人）、步骤条（发现 → 接手 → 派出 → 到场 → 结案，跟网页一样）、现场照片、实时画面、回看 30 秒、小地图 → 全屏地图、现场警示（自动驱离第几级 + 结束驱离；喊话 / 警灯 30 秒 / 警笛 / 全部关，机器人有哪几路才摆；在驱离时警笛照 C-B2 外审按第 3 级）、通知（请求支援 / 已到场）、结论（一排等宽：确认有人 / 误报 / 已处理，备注，结案；不弹窗；10 分钟内能重新打开）、经过（含请求支援、结案结论和备注）、右下角全部急停方块；按了之后的那句话钉在底下。
  - 客户端补了请求支援（POST …/backup）、重新打开（…/reopen）、结案带备注；报警模型补了 resolved_by、verdict。
  - 来报警全屏页（lib/ui/nw/nw_ring.dart，稿 N-ring）：后台值守响铃档的报警发全屏通知，锁屏亮屏拉起 App 直接是这一页；我来处理（确认 → 这件事）/ 只看画面 / 静音 2 分钟（这台手机先不出声，通知照挂，到点没人确认接着响；通知上也有这个按钮）；别人接手了这页自己关。原生：WatchService 全屏通知 + 静音、AlertBell 静音规则（JUnit）、MainActivity 锁屏上显示并把那一条交给 Dart。
  - 派单被拒（refusal.dart，稿 N-refuse）：不弹框，顶上琥珀三角一条说明，去处理 / 知道了一排等宽；没站起来的就地「让 A 站起来」（说明里先叫人看旁边有没有人）。
  - 急停没确认（nw_estop_miss.dart）：全部急停里没回执 / 没停成的那几台，现在页、这件事页顶上红框写站点几点发的、它可能还在动；再发一次急停 / 看它的画面。
  - 派巡逻（patrol_dispatch.dart，稿 N-dispatch）：底部弹层改成整页（深色）：页头这台的名字和电量、它的画面、「临时巡逻，不进日程」、路线和预计时间、圈数、撞日程说排到几点；派出 / 取消钉在底下一排等宽。
  - 几件同时（N-multi）、急停后（N-estop）第 2 期已在「现在」页做了。
